# 华为 PC 营销创作台 · 浙客松

按照赛事手册，通过对话理解任意使用场景，再从“任德耀新建华为PC知识库”读取真实资料、生成文案、独立审核。页面和导出均保留 **场景判断 / 知识库依据 / 图文软文 / 核验结果** 四部分。

当前已接入 DeepSeek。内容仍是待核验草稿：图片只按标题筛选，尚未进行图像内容核验，不能当作可直接发布的成品。实际验证范围见 `验证记录.md`。

开发阶段默认使用**本地资料测试**，读取项目内 `华为PC全板块深度知识库_v7/` 的实际文字和图片；页面、结果、复制与导出均注明“未调用 ima 知识库”。需求理解、写作与审核仍会调用 DeepSeek。正式使用时，在左侧“资料来源”选择**真实资料**，即可通过保留的官方 ima 接口读取指定库；切换模式会清空当前会话和结果，避免混用。

## 打开使用

在本文件夹双击 **`启动.cmd`**。正常会显示“环境检查通过：Python 3.15.0 / Streamlit 1.66.0”。保持窗口开启，访问 http://127.0.0.1:8501/ ，应看到“聊清需求，再开始创作”和聊天输入框。停止时，在启动窗口按 `Ctrl+C`。

1. 自由描述需求。例如：“给大学生社团的视频剪辑同学介绍 MateBook GT 14，他们在宿舍剪辑活动视频、整理素材交给队友，发门店朋友圈，希望邀请到店咨询，不写价格。”
2. 模型整理产品、受众、场景、平台；一次列齐全部缺失或模糊的必需项，补充次数不限，不用假设补齐。内容目标和补充要求选填。
3. 核对摘要后，点击“确认需求，查找资料与图片”：默认从本地资料目录读取；左侧选择“真实资料”时，才通过 ima 读取指定知识库。
4. 查看资料和候选图片，再点击“生成文案并审核”。首次写作已接收所选平台的段落骨架、语气、卖点数、图数和引用规则；程序根据明确的配图段落位置完成排版。审核是独立模型调用，实际未达标的格式、场景或合规问题会带着具体意见及原文退回重写，不设总改写次数上限。可选的措辞润色不会单独触发重写。页面显示轮数，可点击“暂停自动重写”；每轮会继续调用模型。网络或额度错误会暂停并保留进度，处理后可点“继续写作与审核”。
5. 没有未通过项和待改写要求后才展示正文与复制按钮；修改中的旧稿不会作为成稿显示。查看六项核验意见，可复制图文或导出四板块 Markdown 记录。正文的配图位置带名称、来源、说明及待核验标记。若图片不足或原文冲突，会明确说明需补充/确认什么，处理后重新读资料再继续；图片画面等外部待核验事项单独标明，交付仍是待核验草稿。

场景不能只填“学习”“办公”“设计”。应说明实际做什么、用什么软件或怎样操作；需要时再追问同时开多少文件、视频清晰度、工程规模、是否经常外出等影响电脑需求的信息。例如：“用WPS写课程论文，浏览器查文献，同时开十几个PDF，常带去图书馆。”不知道软件名也可直接描述操作。用户的需求不等于该型号已经具备相关性能，产品结论仍只能引用资料。

“图文软文”页会在正文指定位置展示所选的实际图片，带来源及说明。“下载图文与原图（ZIP）”同时保存四部分 Markdown 记录和选中的 PNG/JPEG 图片；解压后保持文档与 `images/` 文件夹在一起，即可按正文引用查看图片。单独复制文字或下载 Markdown 不会自动携带图片文件。

四个平台统一执行真实配图交付检查：写作前剔除缺失、损坏、标题明确错型号或内容完全相同的候选图，实际可完整解码的不同图片达到平台最低图数后才调用写作；交付前再核对选中图片、图数及正文插图对应关系。页面、复制和导出也重新检查；即使已生成草稿，之后图片丢失也不能继续展示或导出正文，仍可导出含问题说明的四板块记录。没有足够素材时提示补充或重新读取，不靠不断重写文案补图片。不能保证库中为任意型号和场景都备齐所需图片；文件实际可见也不等于已完成画面型号及场景适用性核验，仍须查看核验结果。

平台规则同时用于写作与审核，不能只换标题或平台名称：

| 平台 | 成稿格式 | 配图 |
| --- | --- | --- |
| 公众号 | 标题、导语、分段正文、结尾行动引导 | 2–4张，标明段落位置 |
| 小红书 | 口语化标题、短段落、场景描述、话题标签、交流引导；禁虚构体验 | 3–6张 |
| 门店朋友圈 | 短文、一个核心卖点、咨询或到店引导 | 1–3张 |
| 门店海报 | 主标题、副标题、1–3条简短卖点、一句行动引导 | 1张主视觉 |

具体场景决定内容切入点、卖点组织和表达；平台决定结构、语气、图数和行动引导。本地程序检查可量化的结构、图数、正文配图标记，审核角色再检查语气、场景是否贴合和事实依据。模型判断仍可能漏检，核验记录不是零错误保证。

八类常见场景的内容重点保存在 `prompts/scenario_reference.md`，用于理解与写作参考，不限制用户输入，也不代表具体型号已具备相关功能。

修改需求后，旧素材会保留并标明来自先前任务；需重新确认、读取后才能生成。失败提示单独显示，不加入正常对话；处理结束后可重试。清空会同时删除本次聊天、确认记录和页面结果。记录只保存在当前浏览器会话，需要保留时请导出。

## 环境与本机配置

固定 Python **3.15.0**、Streamlit **1.66.0**；已验证 Node.js **24.19.0**。不自动升降级。Node.js 用来执行官方 ima 脚本，要求版本不低于18。图片完整读取检查使用当前 Streamlit 环境已经安装的 **Pillow 12.3.0**；已将这个实际验证过的版本明确记录进 `requirements.txt`，未联网安装或修改本机版本。模型和 ima 调用仍使用标准库，没有增加模型 SDK。

在项目 `.env` 填写以下配置。密钥是程序访问服务的凭证，只留本机，不发送聊天或提交到仓库。

```dotenv
IMA_OPENAPI_CLIENTID=填你的ima访问配置
IMA_OPENAPI_APIKEY=填你的ima访问配置
DEEPSEEK_API_KEY=填你的DeepSeek密钥
DEEPSEEK_MODEL=deepseek-flash
```

`.env.example` 为空白模板；已有 ima 配置无需重填。程序每次请求重新加载 `.env`，保存后即可使用。侧栏“密钥已填写”只表示检测到值，首次真实请求才验证有效性。DeepSeek 额度和费用以账号实际情况为准。

模型及接口根据 2026-10-18 的 [DeepSeek 官方文档](https://api-docs.deepseek.com/) 和 [JSON 输出说明](https://api-docs.deepseek.com/guides/json_mode) 配置，使用 `https://api.deepseek.com/chat/completions`。无效密钥、余额不足、请求过频、连接超时和异常返回均有单独处理。

官方 ima Skill 完整目录为 `ima-skill/`，统一入口 `ima-skill/ima_api.cjs`，不搬走单个脚本或修改官方包。访问账号须已加入指定共享库。

PowerShell 中也可执行：

```powershell
.\启动.ps1
```

找不到指定 Python 时：

```powershell
.\启动.ps1 -PythonPath "你的Python3.15.0安装位置\python.exe"
```

正常启动结果同上。若系统禁止执行本地脚本，双击 `启动.cmd` 即可，它只为本次启动放行脚本。迁移电脑时，在双方统一的 Python 中按 `requirements.txt` 安装依赖，并在新电脑独立填写凭证；兼容问题先共同确认再调整版本。

## 项目结构与合作方式

双方各自开发完整项目，之后合并或择优，旧插件分工已取消。搭档设计资料到达后再对齐，不预先承诺完全兼容。

| 文件 | 作用 |
| --- | --- |
| `app.py` | 对话界面、会话状态、确认、四板块、导出 |
| `agent.py` | 组织需求理解、资料读取、写作与审核 |
| `llm.py` | 三个角色共用的 DeepSeek JSON 调用 |
| `requirements_review.py` | 校验需求清单、批量列齐缺项、持续澄清及确认 |
| `content_review.py` | 校验事实引用、正文配图、平台结构及六项审核结果 |
| `tools.py` | ima 检索、读原文和下载图片，沿用官方脚本；已收紧相近型号隔离与目录追溯 |
| `local_materials.py` | 显式读取项目内的本地测试资料，保留型号隔离、文件来源和测试提示 |
| `image_assets.py` | 校验项目内实际图片，生成带相对图片引用的图文原图下载包 |
| `config.py` | 项目相对路径、本机配置、环境与平台规则 |
| `prompts/` | 三角色提示词、共同约束、八类场景参考 |
| `frontend_mock.py` | 仅供离线测试构造虚构数据，不接入页面 |
| `tests/` | 离线检查，以及单独手动运行的真实连接检查 |
| `outputs/`、`.ima-state/` | 本地素材与验证记录，均不纳入 Git |

Streamlit 直接调用 Python 函数，没有额外的 HTTP 后端。`agent.chat(user_text, history)` 仍可按两个参数调用；页面额外通过关键字 `state` 传入前次已验证的需求清单。前端保存聊天，后端不修改传入的历史。

## 验证

在本文件夹运行：

```powershell
.\启动.ps1 -CheckOnly
.\启动.ps1 -Test
```

分别应显示“环境检查通过”和测试结尾 `OK`。离线测试不访问真实服务，覆盖追问、确认、场景自由输入、错误恢复、审核阻断、导出、本地来源提示及真实/本地/模拟隔离。

单独验证 DeepSeek（发送一条简短真实请求）：

```powershell
.\启动.ps1 -CheckModel
```

正常显示“DeepSeek 真实连接成功，JSON 返回检查通过”。

日常测试先用本地；以下命令仅在明确需要检查真实 ima 时运行，会消耗相应服务额度：

```powershell
.\启动.ps1 -CheckIma
```

成功会列出资料及图片标题，`status` 为 `ok`，此检查不生成文案。使用同一 Python 执行 `-m tests.live_agent_smoke --max-rounds 5` 可复用这份本地资料验证三角色链路，真实生成记录保存于 `outputs/deepseek_smoke/创作记录.md`。该脚本默认最多检查5轮，打印具体失败项后暂停，避免调试时持续消耗模型额度；这个测试限额不影响页面自动重写。只有实际生成草稿才返回成功状态。这些手动检查会访问相应服务。

测试默认使用本文件夹内的资料，正式使用须选择“真实资料”，从指定 ima 知识库读取。真实读取失败时直接说明原因，不会自动改用本地资料或模拟结果。ima 返回“资料获取次数已达上限，请明天再尝试”时，页面明确显示“ima 原文读取额度已用尽”并保留官方原因，同时停止剩余读取；是否恢复须以之后的实际接口结果为准。

页面仅保留“本地资料测试”和“真实资料”，已移除“界面联调”和模拟情况入口。失败、超时等情况通过离线测试验证，不作为页面工作模式。

侧栏“检查知识库连接”仅在“真实资料”模式可用，使用官方 ima Skill 实时检查指定库，展示时间及脱敏接口摘要；“凭证已填写”本身不代表已经连通，也不保证原文读取额度充足。本地模式不会自动检查远程连接。自动修改的轮次和意见只保存在本次会话，关闭页面或重启服务后不能保证恢复；需要留存的最终记录请导出。

## 当前边界与后续工作

每次最多读取三份文字资料和平台最低数量的候选图片；文档支持 UTF-8 Markdown / txt，图片支持 JPEG / PNG，单文件最多8 MiB。读取文字最多64000字符；发送模型时每份取前16000字符。查询有次数与总时长限制，不声称已查遍知识库。

本地检查能确认引用原句确实存在；是否充分支持文案含义还需审核，模型仍可能漏检。图片内容、具体型号与版本需要补充核验。任一未完成事项均保留待核验，资料冲突阻断文案。当前还需完成图片内容核验、各平台真实样例及图文成品打磨，并准备赛事要求的说明书、GitHub与魔搭展示、复赛视频。

原始赛事资料、凭证、官方压缩包和运行素材均不纳入源码提交。每个改动单元自动保存本机 Git 版本记录，未自动推送。
