# 场景内容重点参考

以下仅为理解与写作的参考，不是允许输入的场景清单，不能把新场景强行塞入这八类。应结合用户描述调整切入点、卖点顺序与语气，必要时组合多个参考。这里的方向不是任何具体型号的已证实功能。

- 开学季：围绕学习任务、随身携带、多设备协作安排内容；续航等事实须有具体型号资料。
- 职场办公：围绕会议、差旅、文档处理和工作协同安排内容，不虚构安全能力。
- 内容创作：围绕屏幕、素材流转和创作流程安排内容，不编造软件测试成绩。
- 家庭换新：围绕日常使用、易用性和数据迁移安排内容，不承诺未经证实的服务。
- 企业采购：围绕部署、管理和团队需求安排内容，采购政策必须有资料依据。
- 门店到访：突出一个具体使用问题和到店体验理由，避免堆砌所有卖点。
- 新品首发：说明新品适用人群与变化；价格和权益缺失时不自行补充。
- 节日营销：围绕送礼或家庭购机需求安排内容，不虚构优惠、补贴与库存。
