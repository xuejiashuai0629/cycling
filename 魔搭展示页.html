华为 PC 营销创作台

浙客松 · 华为产业进阶赛道 · AI+华为PC营销软文智能体

这是项目展示页，提供功能介绍、真实运行截图及源码入口；交互创作台请按照 GitHub README 在本地运行。图片画面型号仍需人工核验，不将待确认事项标成通过。

一句话介绍：面向华为门店导购的自研营销 Agent。导购用自然语言描述任务，系统完成"理解需求 → 查找资料 → 选择图片 → 生成内容 → 核验结果"闭环，交付有知识库依据、经过六项核验的图文软文。ima 仅作为产品事实与图片素材来源，策略、组织与核验均为自研。

核心流程

需求理解（缺项一次列齐，追问不用假设）→ 用户确认 → ima 知识库检索 → 图文写作 → 独立审核（六项检查，不过退回重写）→ 四板块交付（场景判断 / 知识库依据 / 图文软文 / 核验结果）

关键能力

场景自由描述笼统场景强制追问四平台规则事实逐条对应原文相近型号隔离合规拦截正文真实图片ZIP 图文下载130 项离线测试
  • 不懂就问，绝不硬写：只填"学习""办公"会被继续追问实际任务、软件与负载；型号疑似有误先澄清。
  • 无依据不生成：价格、补贴、库存、绝对化宣传、无依据对比、竞品贬低一律拦截或标注待确认；知识库未收录的型号不凭模型记忆编造。
  • 证据链交付：每个产品事实对应知识库原文摘录；每张图片带来源、说明与插入位置；资料冲突阻断并提示人工确认。
  • 诚实标注：图片画面型号、外部待确认事项明确标"待核验"，不标全部通过。
